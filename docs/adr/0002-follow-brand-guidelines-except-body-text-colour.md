# Follow the brand guidelines exactly, except body text colour

The Design System follows `Chesamel-Brand-Guidelines.pdf` to the letter, including DM Sans for subheadings even though Figtree is the stated primary typeface. The one deliberate deviation is body text: the guidelines specify Grey (#7F848C), which is about 3.8:1 contrast on white and fails WCAG AA (4.5:1). On the website body text uses Dark Grey (#3C404D); Grey is kept for large text, tags and captions. Do not "correct" body text back to Grey.

Arabic text uses IBM Plex Sans Arabic, because Figtree has no Arabic glyphs and the guidelines don't name an Arabic face. Secondary and accent colours stay limited to small accents (tags, icons) and are not assigned per Pillar.
